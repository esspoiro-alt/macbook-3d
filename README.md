# MacBook 3D

Фотореалистичный 14" MacBook Pro Silver для кейсов портфолио.

## Логика
- 0% — ноутбук полностью закрыт.
- При скролле двигается только крышка вокруг штатной петли.
- 100% — крышка открыта примерно на 108°.
- Основание остаётся на месте.
- Ракурс фронтальный, под композицию Diana Ro.
- Экран является заменяемой текстурой.

## Экран
Проект пытается загрузить `screen.png` из корня репозитория.
Если файла пока нет, включается временная тестовая текстура.

Чтобы заменить кейс, нужно заменить только `screen.png`. Модель, камера, свет и анимация не меняются.

## Preview
Откройте `index.html` через обычный web-сервер или GitHub Pages.
HTML использует Three.js с jsDelivr и исходный GLB MacBook из:
https://github.com/AnubhavChaturvedi-GitHub/macbook-pro-threejs
